Programming your locomotive

Getting your locomotive to work has never been easier. On this page, you can upload the code to the microprocessor with one push of a button. No further software needed.

Please note that this is still an experimental feature. If you find any issues, please let us know!

Please use the right hardware

We recommend using the Wemos D1 V3 Mini (V1, V2 or V4 also work) with the TB6612FNG motor driver

Click here to see the exact electronics that you need

Firmware installation

Follow these steps in order. The actual firmware installer opens directly on this page.

1

Install the USB driver

Many Wemos D1 mini boards use a CH340/CH341 USB chip. Installing this driver helps your computer recognize the board.

Windows driver Mac driver

After installing the driver, unplug and reconnect the Wemos D1 mini.

2

Connect the locomotive controller

Plug the Wemos D1 mini into your computer with a data-capable USB cable. Some charging cables power the board but do not allow programming.

3

Install the firmware

Click the install button below. When your browser asks for a serial port, choose the Wemos / USB serial device.

Your browser does not support USB serial flashing. Please use Chrome or Microsoft Edge on desktop. The installer needs to be opened directly in Chrome or Microsoft Edge on an HTTPS page.

Keep the board connected until installation is complete.

4

Connect to the locomotive Wi‑Fi

After installation, the controller restarts and creates its own Wi‑Fi network. Open your Wi‑Fi settings and connect to:

PRM LOCOMOTIVE

The default network has no password. While connected to the locomotive Wi‑Fi, your device may temporarily lose normal internet access. This is expected.

5

Optional: name your locomotive network

While connected to the locomotive Wi‑Fi, type or copy this address into your browser:

http://192.168.4.1

On the setup page, you can rename the locomotive Wi‑Fi and optionally add a password. You can also skip this step and keep using the default network name.

Password note: leave the password empty for an open network, or use at least 8 characters to avoid setup errors.
6

Reconnect and start driving

After saving the new Wi‑Fi name or password, the controller restarts. Connect to the locomotive Wi‑Fi network, then open your PRM controller app.

The controller address remains:

192.168.4.1

Forgotten Wi‑Fi password?

No problem. Connect the Wemos D1 mini to your computer again and repeat the install steps. When asked, choose the clean install / erase option. The controller will return to the default Wi‑Fi network:

PRM LOCOMOTIVE

Then connect to it and open http://192.168.4.1 to set a new name or password.

Need help?

I do not see a USB serial device.

Install the Windows or Mac USB driver from step 1, reconnect the board, and try another USB cable.

The install button does not appear.

Use Chrome or Microsoft Edge on a desktop or laptop computer. Safari and mobile browsers are not recommended.

I renamed the Wi‑Fi and now the old network disappeared.

That is normal. Look for the new name you entered, connect to it, and then open http://192.168.4.1.

I cannot access the internet while connected to the locomotive.

This is expected. The locomotive creates its own local Wi‑Fi network for control. Reconnect to your normal Wi‑Fi network when you are finished setting it up.
