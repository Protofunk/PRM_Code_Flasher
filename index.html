Wemos D1 Mini / ESP8266

Firmware Installer

Plug the Wemos D1 mini into USB, use Chrome or Edge, then click Install. No Arduino IDE needed on the client computer.

1. Connect the board

Use a data-capable USB cable. Some charging-only cables will power the board but will not show a serial port.

2. Install firmware

Click the button below and select the USB serial port for the Wemos D1 mini.

Your browser does not support Web Serial. Please use Chrome or Edge on desktop.

3. First-time setup

After flashing, your firmware can start its own setup Wi-Fi network, for example: 

TrainController-Setup

Then clients can enter Wi-Fi, server URL, device name, or train ID in your own setup portal.

Troubleshooting

  • If no port appears, install the CH340 USB serial driver.
  • Use Chrome or Edge. Safari and iOS browsers are not suitable for this workflow.
  • Try another USB cable if the board powers on but is not detected.
  • Close Arduino IDE, serial monitors, or other apps using the same COM port.

Replace firmware/wemos-d1-mini-firmware.bin with your exported Arduino binary.
